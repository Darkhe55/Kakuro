# 数和（Kakuro）

一个基于 Web 的数和（Kakuro，日式数字填空 / 交叉和）谜题游戏：原生 SVG 渲染、实时校验、回溯求解器，以及可逐帧回放的逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5212/**。

> 也可以用 `npm run dev`（不会自动打开浏览器），或 `npm run build` 后 `npm run preview`。

## 游戏规则

- 棋盘由**黑格**与**白格**组成，白格里填 1–9。
- 每一段**连续白格**（横向或纵向）内：
  1. 数字不能重复；
  2. 数字之和必须等于该段对应的提示数。
- 带提示的黑格用两枚小字给出和：
  - **左上角** = 该行右侧那一段白格的和（横向提示）；
  - **右下角** = 该列下方那一段白格的和（纵向提示）。
- 没有提示的方向表示该方向没有白格段。
- 内置 8 道题，全部经过「唯一解 + 逻辑规则可推完」校验。

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 选中该格并循环填数（空 → 1 → … → 9 → 空） |
| 按住拖拽 | 沿路径连续按同一规则涂写 |
| 数字键 1–9 | 给选中格直接填数 |
| 0 / Backspace / Delete | 清空选中格 |
| 右键点格 | 清除该格 |
| 方向键 | 移动键盘光标（自动跳过黑格） |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / L / P | 检查 / 逻辑解题（回放）/ 暂停回放 |
| 「提示一格」按钮 | 提示一格 |
| R / M | 随机抽题 / 音效开关 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| + / − / 视图复位按钮 | 放大 / 缩小 / 复位 |

> 键盘光标存在格子里，选中格会用描边和同段淡色高亮；拖拽和点击都会同步光标。

## 实时校验

- 段内**数字重复**：冲突数字标红；
- 段内**和超限**（已经超过提示和）：整段白格标红、对应提示变红；
- 段已填满但**和不足**：整段标红；
- 段剩余空格**已经无法凑出提示和**（结合“数字不重复”提前判断死路）：整段标红；
- 题面本身缺提示 / 段长超过 9：提示录入错误，整盘提示。

状态栏会汇总「已填 x/y 格 / n 段数字重复 / n 段和超限 / n 段已无法凑出提示和」。

## 自定义题板

点击左侧「自定义」，可以自己出题：

1. **画布局**：在网格上点击（或键盘 `1`）把白格涂成黑格，再点一下还原；`0` / `Backspace` 清空该格。
   - 默认生成 5×5，并自动把**第一行、第一列**涂黑（这是数和的标准结构：保证每个白格左侧/上方都有提示黑格）。
   - 宽高范围 3×3 – 20×20；修改宽高后点「生成网格」。
2. **录提示和**：点击任意黑格，在下方「黑格提示和」面板录入该黑格的横向 / 纵向提示和。
   - 只有该方向真的有白格段时输入框才可用（否则该方向不需要提示）；
   - 提示和取 1–45，段长最多 9 格。
3. **文本导入 / 导出**（推荐批量搭题）：
   - 每行一行、单元格用空格分隔；
   - 白格写 `.`；黑格写 `横.纵`（`0` 表示该方向无提示），也可写 `#` 表示无提示黑格；
   - 例：
     ```
     # # # # #
     # 12.0 0.7 . .
     # . . . .
     # 0.9 . . .
     # # # # #
     ```
4. **保存 / 载入 / 编辑 / 删除**：
   - 「保存到题库」会把题面（布局 + 全部提示和）存入题库，刷新页面后仍在；
   - 保存 / 载入时会自动做**唯一解审计**：无解、多解、题面缺提示都会提示；
   - 题库里自定义题右侧有「编辑」（回填题面继续改，覆盖原题）和「×」删除（**再点一次确认**）；
   - 「载入题板」直接开始玩当前编辑器里的题，并同时入库。

## 逻辑解题与求解

- **逻辑解题**：规则引擎先一次性推演，再逐帧回放：
  1. 唯一候选；
  2. 段和约束（枚举每段所有数字组合 → 单元格候选交集、数字出现位置）；
  3. 反证排除（假设某格填 d，继续传播立刻矛盾则排除 d）。
  回放期间可按 `P` 暂停 / 继续，按钮变为「停止回放」。
- **提示一格**：从参考解里找第一个空格（或错格）揭示。
- **显示解**：内置题直接用题库参考解；自定义题调用回溯求解器。
- **求解器**：以「段」为单位的 MRV 回溯 + 强制传播 + 和区间 / 去重剪枝，带节点与时间预算；自定义题保存时用它做唯一解校验。

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录（`/__store` 中间件）；直接打开 build 后的静态页面时自动降级到浏览器 localStorage。

## 功能

- **题库**：8 道内置题（5×5 / 6×6 / 7×7 / 6×8 / 8×8 / 9×9 / 8×10 / 10×10），全部唯一解 + 逻辑可推完
- **实时校验**：重复、和超限、和不足、无解死路即时高亮
- **自定义题板**：点击 / 键盘画黑格 + 提示和录入 + 紧凑文本导入导出 + 唯一解审计 + 编辑回填 + 两步确认删除
- **逻辑解题**：规则推演逐帧回放，显示每一步理由，可暂停
- **提示一格 / 显示解 / 检查 / 清空 / 撤销 / 重做**
- **进度保存**：自动保存每个题目的进度与键盘光标
- **音效特效**：Web Audio 合成拨弦、水滴与数字落子动画，无外部资源
- **缩放 / 平移**：滚轮缩放，中键或拖拽平移

## 命令

```bash
npm install
npm run dev       # 开发服务 http://127.0.0.1:5212/
npm start         # 开发服务 + 自动打开浏览器
npm run build     # tsc --noEmit + vite build
npm run preview   # 预览 build 产物
npm run gen       # 重新生成内置题库（唯一解 + 逻辑可解过滤）
npm run check     # 题库审计：题面结构 / 参考解 / 唯一解 / 逻辑回放 soundness
npm run ui-check  # Playwright 冒烟测试（需先启动 dev 或 preview）
```

浏览器验证脚本使用 `playwright-core` + 本机 Edge（可用环境变量 `EDGE_PATH` 覆盖路径），截图输出到 `output/playwright/`。

## 已知限制

- 数和规则要求单段 1–9 格；自定义题板若出现超过 9 格的白格段会提示题面非法（当前不会自动拆分）。
- 逻辑解题器只做可证明的排除，不猜测；内置题都保证能推完，但极端自定义题可能中途卡关，此时可用「显示解」。
- 自定义题保存时的唯一解校验有节点 / 时间预算：20×20 的大盘面可能提示「求解超时」，可减少盘面或补全提示后重试。
- 题目存档按 `puzzleId` 区分；删除自定义题会同时清除该题的进度。
